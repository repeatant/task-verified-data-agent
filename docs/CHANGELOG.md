# Changelog

## v1.0.0

2026-11-07。动态参考审查与 LangGraph 单框架版本；这是有明确数据与执行边界的研究原型，不是通用 SQL 正确性证明器。

### 编排与核验

- 当前 Agent 编排统一使用 LangGraph。保留预设性质路径 `run_graph_case` 与动态参考路径 `run_discovery`，两者使用不同验收契约。
- 动态路径包含分离上下文的生成、核验与盲态独立核算；执行证据用于区分 SQL 修改、参考替换和业务澄清。
- 参考版本和已发现反例保留，恢复后重新执行；上下文分离不宣称消除共同误解，也不提供语义正确性证明。
- 参考计划的格式反馈增加通用 AST 诊断，指出受限语言不支持的语句、属性调用等构造；不提供业务计算答案，不放宽执行权限。

### 移除 DB-GPT 运行路径

- 移除活跃适配层、原生 Agent 运行入口、安装脚本、专属依赖与集成测试。
- 模型配置继续使用独立 `QwenConfig`；真实调用保持显式开启和累计费用约束。
- 当前使用文档只保留 LangGraph 命令。旧反馈实验 CLI 不再作为本版运行入口。
- 独立挑战评测默认记录本次纯核验源码摘要；源码在评测中变化或发生执行异常时返回失败，不再只标记完成。
- 离线回归包含阻断 DB-GPT 导入后实际运行 LangGraph 修复流程的检查。
- 最终离线回归 1,077 项通过，Ruff 检查及格式检查通过。

### 真实 API 联调

- 三条受控参考审查分别完成参考替换、SQL 修复和明确舍入保留；SQL 与两份计算通过七组开发评分数据。
- 订单去重任务由真实模型自然生成，SQL 与两份参考通过七组开发评分数据；固定任务验证跨进程恢复，恢复阶段无新增模型请求。
- 首轮非法参考程序导致的未完成运行保留，修复通用诊断后补测。本轮共 26 次请求、53,194 Token，不合并为一次冻结成功率。完整范围见[公开联调证据](../tests/fixtures/discovery/v1_live_validation.json)。
- 保留此前的源码分层、`docs/` 文档集中管理和 `tests/fixtures/` 示例组织。

### 迁移边界

- 未承诺恢复旧 DB-GPT 会话或把旧报告转为 LangGraph 报告。代码与配置变化时应创建新线程，不能绕过检查点绑定。
- 冻结历史源码与原始证据保持原样，仅用于离线回放和审计；其中旧适配文件不是本版运行依赖。
- 29.1% 诊断字符压缩、7.0% 输入 Token 压缩属于历史 DB-GPT 实验，没有迁移成 LangGraph 指标。
- 旧文件清单与上游 pin 移至 `docs/history/`，只描述当时源码，不验证当前目录。
