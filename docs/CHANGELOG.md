# Changelog

## v1.1.0

2026-11-22 · SQL 核验工作台。[体验包与发布说明](https://github.com/repeatant/task-verified-data-agent/releases/tag/v1.1.0)

- 工作台提供数据预览、口径澄清、核验记录、SQL 查看和 CSV 导出。体验包包含预构建网页、订单示例及 Palmer Penguins 公开数据。
- 交付前在最多 500 条源记录的完整登记库上运行候选 SQL 和两份参考程序，分开记录样本检查和整库复核。对漏算预览之外物种的候选 SQL 和参考程序均有回归用例。
- 分歧调查区分签核依据和辅助查询。内置真实千问回放可离线查看，公开数据回放的 2009 年观测数为 120，与原始 CSV 独立计数一致。

### 三方分歧处理实验

2026-11-09。独立实验分支，不替换 `run_discovery` 默认流程。

- 支持只读查询及 SQL、参考、独立核算三类程序的定向修订，保留执行依据和版本历史。
- 接受最新重放中的具体检查引用，仍完整检查全部当前数据、未决假设和最终来源执行。
- 六条真实模型开发轨迹正确交付 4/6；引用接口修复后原响应离线回放 5/6，零新增 API。
  首轮结果和全部原始记录保留，未支持优于简单自审的结论。
- 全量离线回归 1,813 项通过，Ruff 通过。详见[实验记录](experiments/DISPUTE_RECOVERY_RESULTS.md)。

### 扩展评测与工程修复

2026-11-07。完成 980 条主实验、20 条稳定性复测与 80 条新题配对确认，原始失败、冻结源码及费用记录完整保留；详见[扩展结果](experiments/EXPANDED_RESULTS.md)。

- 新增受约束的多表 SQLite 数据适配、公开数据选样、独立评分、四组基线和三组消融。公开题与受控故障分别报告，拒绝交付不计为成功。
- 扩展实测未支持完整核验流程优于简单自修复；严格 JSON Schema 的新题确认也未显示正确交付改善。结构化适配器保持显式启用，默认行为不变。
- Windows 原子文件替换仅对 WinError 5/32 作有限重试，最多等待 310 ms；不会重复执行计费、费用预留或模型请求，持续失败仍停止。
- 新增预算续跑与独立审计工具，分别记录未知用量及已经入账的失败请求；不重跑已有质量结果，不退回保守预留。
- 合并后 1,659 项离线测试通过。工程修复与格式整理发生在冻结实验之后，不回填旧分数；精确实验版本以保存的协议及源码快照为准。

## v1.0.0

2026-11-07。动态参考审查与 LangGraph 单框架版本；这是有明确数据与执行边界的研究原型，不是通用 SQL 正确性证明器。

### 编排与核验

- 当前 Agent 编排统一使用 LangGraph。保留预设性质路径 `run_graph_case` 与动态参考路径 `run_discovery`，两者使用不同验收契约。
- 动态路径包含分离上下文的生成、核验与盲态独立核算；执行证据用于区分 SQL 修改、参考替换和业务澄清。
- 参考版本和已发现反例保留，恢复后重新执行；上下文分离不宣称消除共同误解，也不提供语义正确性证明。
- 参考计划的格式反馈增加通用 AST 诊断，指出受限语言不支持的语句、属性调用等构造；不提供业务计算答案，不放宽执行权限。

### 移除 DB-GPT 运行路径

- 移除活跃适配层、原生 Agent 运行入口、安装脚本、专属依赖与集成测试。
- 模型配置继续使用独立 `QwenConfig`；真实调用保持显式开启和累计费用约束。
- 当前使用文档只保留 LangGraph 命令。旧反馈实验 CLI 不再作为本版运行入口。
- 独立挑战评测默认记录本次纯核验源码摘要；源码在评测中变化或发生执行异常时返回失败，不再只标记完成。
- 离线回归包含阻断 DB-GPT 导入后实际运行 LangGraph 修复流程的检查。
- 最终离线回归 1,077 项通过，Ruff 检查及格式检查通过。

### 真实 API 联调

- 三条受控参考审查分别完成参考替换、SQL 修复和明确舍入保留；SQL 与两份计算通过七组开发评分数据。
- 订单去重任务由真实模型自然生成，SQL 与两份参考通过七组开发评分数据；固定任务验证跨进程恢复，恢复阶段无新增模型请求。
- 首轮非法参考程序导致的未完成运行保留，修复通用诊断后补测。本轮共 26 次请求、53,194 Token，不合并为一次冻结成功率。完整范围见[公开联调证据](../tests/fixtures/discovery/v1_live_validation.json)。
- 保留此前的源码分层、`docs/` 文档集中管理和 `tests/fixtures/` 示例组织。

### 迁移边界

- 未承诺恢复旧 DB-GPT 会话或把旧报告转为 LangGraph 报告。代码与配置变化时应创建新线程，不能绕过检查点绑定。
- 冻结历史源码与原始证据保持原样，仅用于离线回放和审计；其中旧适配文件不是本版运行依赖。
- 29.1% 诊断字符压缩、7.0% 输入 Token 压缩属于历史 DB-GPT 实验，没有迁移成 LangGraph 指标。
- 旧文件清单与上游 pin 移至 `docs/history/`，只描述当时源码，不验证当前目录。
